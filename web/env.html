项目配置
Servlet 容器Apache Tomcat 9.0.115
JDKOracle OpenJDK 21.0.4
文件编码-Dfile.encoding=UTF-8
Web 项目目录jspShixun\web

jar 包用途
gson-2.8.5.jarGoogle 写的 JSON 字符串处理工具包

jsoup-1.11.2.jarHTML 网页标签解析包
jstl.jarJSP 标准标签库核心包
standard.jarJSTL 标签库实现依赖
servlet-api.jarServlet / JSP 核心 API
mysql-connector-java-5.1.26-bin.jar让 Java 连上 MySQL 数据库
